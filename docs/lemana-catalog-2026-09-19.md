## Покрытие и незакрытый запрос

Полная таблица [treatment-coverage-2026-09-19.csv](treatment-coverage-2026-09-19.csv) строится из тех же фильтров, которые использует приложение: растение, проблема и условия выращивания. Варианты с заблокированным назначением не учитываются. Колонки отдельно показывают все варианты и варианты с подтверждением каталога Лемана Про. Несколько препаратов одного производителя считаются одним производителем.

**Условие «не менее пяти препаратов разных производителей на каждую проблему» выполнено не для всех сочетаний.** По пять производителей подтверждены для тли и трипсов на розе и пионе, а также колорадского жука на картофеле. Для остальных сочетаний в таблице указано фактическое количество, включая ноль. В частности, для снежной плесени газона не удалось подтвердить подходящие варианты из этого каталога с достаточным регламентом для назначения.

Список не дополнен средствами с произвольно расширенными культурами, промышленными регламентами вместо ЛПХ или неподтверждёнными дозами ради достижения числа пять. Для дальнейшего заполнения пробелов нужны конкретные этикетки подходящих средств или расширение проверенного каталога источников. Автоматический повтор обработок при замене средства не наследуется от предыдущего препарата.

## Проверенные различия

- Клещевит для растений не подменён Клещевитом Супер для обработки территории от иксодовых клещей.
- Топаз и Скор имеют производителя Syngenta; размещение у Августа не превращает их во второго производителя.
- Для Биотлина использована текущая карточка: у яблони указан срок ожидания 60 дней. Старый найденный PDF с другими данными не принят за актуальную инструкцию.
- Триходерма имеет разные строки для корневого полива и листовой обработки, открытого и защищённого грунта. Корневые применения находятся в разделе корневых процедур.
- «Пятнистости листьев» — общая категория. Для Скора у розы явно указана чёрная пятнистость, без обещания лечения всех причин пятен.
- У Искры Двойной эффект на доступной странице нет полного набора ограничений: перед назначением пользователь должен подтвердить срок ожидания и кратность по своей этикетке. Карточка не выдаёт их за проверенные числа.
