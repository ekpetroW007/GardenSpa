Garden Spa — персональный помощник для владельцев садов, дачных участков и домашних растений. Приложение помогает организовать регулярный уход, планировать процедуры и не забывать о важных делах.
Создавайте отдельные сады и объединяйте в них растения. Для каждого растения можно назначить процедуру: полив, подкормку, обработку, пересадку или любую другую задачу. При необходимости выберите препарат и сохраните информацию о его назначении и норме расхода.
